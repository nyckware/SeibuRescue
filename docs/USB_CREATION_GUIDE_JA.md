# SeibuRescue - ブータブル USB メモリ作成マニュアル

## 1. 概要と ISO バリエーションの選択

書き込みを行う前に、対象となる PC の仕様（CPU・メモリ容量）や作業目的に合った適切な ISO イメージファイルを選択してください：

| ISO バリエーション | 対象アーキテクチャ | 推奨メモリ (RAM) | 主な用途・特徴 |
| :--- | :--- | :--- | :--- |
| **`SeibuRescue-24.04-amd64.iso`** | 64ビット（x86_64 / UEFI & BIOS） | 2GB 以上 | 通常のフル機能版（バックアップ、復元、クローン、イメージ抽出に対応）。 |
| **`SeibuRescue-18.04-i386.iso`** | 32ビット（i386 / レガシー BIOS） | 256MB 〜 512MB | 工場の旧型設備PC（Pentium 4、初期Atom、低メモリ機）向け。 |
| **`SeibuRescue-RestoreOnly-24.04-amd64.iso`** | 64ビット（x86_64 / UEFI & BIOS） | 2GB 以上 | 現地保守・リストア作業に特化した復元専用版。 |
| **`SeibuRescue-RestoreOnly-18.04-i386.iso`** | 32ビット（i386 / レガシー BIOS） | 256MB 〜 512MB | 工場設備の故障復旧に特化した軽量復元専用版。 |

## 2. 必要な機器と事前準備

1. **USB メモリ**:
   - 容量: 最低 **4 GB**（システムのみであれば 2GB でも動作可能）。
   - 推奨: **16 GB 〜 64 GB**（空き領域にバックアップイメージを直接保存したい場合）。
2. **ダウンロード済み ISO ファイル**:
   - 必要に応じて `sha256sum SeibuRescue-*.iso` 等でファイルの破損がないかハッシュ値を確認してください。
3. **USB メモリ内の既存データのバックアップ**:
   - 書き込みを行うと、USB メモリ内のデータはすべて消去されます。必要なデータは事前に別の場所へ退避させてください。

## 3. 方法 1: Rufus（Windows 推奨・産業用および旧型PC向け）

Windows 環境では、**Rufus** の使用を強く推奨します。パーティション構成（MBR / GPT）やブート方式（レガシー BIOS / UEFI）を細かく指定できるため、工場の産業用 PC でも最も確実に起動できます。

### 操作手順：
1. [https://rufus.ie](https://rufus.ie) から **Rufus**（ポータブル版で可）をダウンロードします。
2. 作業用 Windows PC に USB メモリを接続します。
3. Rufus を起動し、以下の設定を行います：
   - **デバイス**: 接続した USB メモリを選択します。
   - **ブートの種類**: **「選択」** ボタンを押し、ダウンロードした `SeibuRescue-*.iso` を指定します。
   - **パーティション構成**: **「MBR」** を選択します。
     - *(※ MBR を選択することで、古いレガシー BIOS PC と最新の UEFI PC の両方で起動可能になります)*。
   - **ターゲットシステム**: **「BIOS (または UEFI-CSM)」** を選択します。
   - **ボリュームラベル**: 任意の名前（例: `SEIBURESCUE`）を入力します。
   - **ファイルシステム**: `FAT32 (既定)`。
4. **「スタート」** をクリックします。
5. 「ISOHybrid イメージが検出されました」というダイアログが表示された場合：
   - **「ISO イメージモードで書き込む (推奨)」** を選択して **「OK」** をクリックします。
   - *(※ 万が一、古い PC で起動しない場合は、再度「DD イメージモード」で書き直してください)*。
6. 「データ消去の警告」で **「OK」** をクリックします。
7. 進捗バーが緑色の「準備完了」になったら **「閉じる」** をクリックして完了です。

## 4. 方法 2: BalenaEtcher（Windows / macOS / Linux 簡単操作）

**BalenaEtcher** は、直感的で分かりやすいクロスプラットフォームの書き込みツールです。

### 操作手順：
1. [https://etcher.balena.io](https://etcher.balena.io) から BalenaEtcher をダウンロードしてインストールします。
2. USB メモリを PC に接続します。
3. BalenaEtcher を開きます：
   - **Flash from file**: `SeibuRescue-*.iso` を選択します。
   - **Select target**: 書き込み先の USB メモリにチェックを入れます（内蔵ディスクと間違えないよう容量を確認してください）。
   - **Flash!**: クリックして書き込みを開始します。
4. 管理者権限（パスワード）を求められたら承認します。
5. 検証（Validating）が 100% になり「Flash Complete!」と表示されたら、USB メモリを安全に取り外します。

## 5. 方法 3: Linux ターミナル（`dd` コマンド）

Linux 環境では、追加ソフトをインストールすることなく標準の `dd` コマンドで確実なセクター書き込みが可能です。

### 操作手順：
1. ターミナルを開き、USB メモリのデバイス名を確認します：
   ```bash
   lsblk -d -o NAME,SIZE,MODEL,TRAN
   ```
   *(例: `/dev/sdb` や `/dev/sdc`。※ `/dev/sdb1` などのパーティション番号ではなく、ドライブ全体を指定します)*。

2. 自動マウントされているパーティションがあれば解除します：
   ```bash
   sudo umount /dev/sdX* 2>/dev/null || true
   ```

3. ISO を USB デバイスへ直接書き込みます：
   ```bash
   sudo dd if=SeibuRescue-24.04-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync
   ```
   *(※ `SeibuRescue-24.04-amd64.iso` は実際のファイル名、`/dev/sdX` は先ほど確認した USB のデバイス名に置き換えてください)*。

4. 処理が完了したら、バッファを同期します：
   ```bash
   sync
   ```
5. これで安全に USB メモリを取り外せます。

## 6. 方法 4: Ventoy（複数 ISO をまとめられるマルチブート）

**Ventoy** を使用すると、1本の USB メモリ内に 64bit版と 32bit版の両方の ISO ファイルをそのままコピーして入れておき、起動時にメニューから選択して起動させることができます。

### 操作手順：
1. [https://www.ventoy.net](https://www.ventoy.net) から Ventoy を入手し、起動します。
2. 対象の USB メモリに Ventoy をインストール（初期化）します。
3. 作成完了後、ファイルマネージャーに `Ventoy` というドライブが表示されます。
4. そのドライブの中に `SeibuRescue-24.04-amd64.iso` や `SeibuRescue-18.04-i386.iso` をドラッグ＆ドロップでコピーします。
5. PC 起動時に Ventoy のメニューが表示され、起動したい ISO を選ぶことができます。

> [!NOTE]
> **産業用 PC での注意事項**: Ventoy は大変便利ですが、工場などに設置されている一部の古い産業用マザーボード（Pentium 4、初期 Atom、2000〜2010年頃の装置）では、Ventoy のブートローダーと相性問題が発生し起動しない場合があります。古い現場マシンで確実に起動させたい場合は、**方法 1（Rufus MBRモード）** または **方法 3（`dd`）** による専用 USB の作成をおすすめします。

## 7. 活用テクニック: 同じ USB メモリ内に「バックアップ保存領域」を作成する

SeibuRescue 自体のシステム容量は 1GB〜1.6GB 程度のため、32GB や 64GB などの大容量 USB メモリを使用する場合、残りのスペースを「バックアップイメージ保存用のデータパーティション」として活用すると非常に便利です。

### パーティションエディタ（GParted や KDE ディスク管理）での設定例：
1. SeibuRescue 起動後（または Linux PC 上）で **パーティションマネージャー（GParted）** を開きます。
2. 右上のドライブ選択から作成した USB メモリを選びます。
3. 未割り当て（Unallocated）の空きスペースに第2パーティションを作成します：
   - **ファイルシステム**: **NTFS**（Windows、Linux 双方で読み書きでき、大容量単一ファイルに対応するため推奨）または **exFAT**。
   - **ラベル**: `BACKUPS`
4. 変更を適用します。
5. SeibuRescue でバックアップを実行する際、**手順 3（保存先ドライブの選択）** でこの `BACKUPS` パーティションがローカルドライブとして即座に認識・選択できるようになります。

## 8. 作成した USB メモリからの起動手順

1. 作業対象パソコンの電源を完全に切ります。
2. 作成した USB メモリを PC の USB ポート（ハブを経由せず直接）に差し込みます。
3. 電源ボタンを押し、**すぐに各メーカーの「ブートメニューキー」を連打**（1秒に1回程度）します：

| パソコンメーカー / マザーボード | 代表的なブートメニューキー |
| :--- | :--- |
| **Dell（デル）** | `F12` |
| **HP / Compaq** | `F9` または `Esc` を押した後に `F9` |
| **Lenovo / ThinkPad** | `F12`（または `Enter` を押した後に `F12`） |
| **ASUS（エイスース）** | `F8` または `Esc` |
| **Acer / 東芝 / 富士通 / NEC** | `F12` |
| **産業用 PC / その他（Advantech 等）** | `F11`、`F12`、`F8`、または `Esc` |

4. 画面に表示された一覧から USB メモリを選択して **Enter** を押します。
5. SeibuRescue の起動画面が表示され、デスクトップが立ち上がります。

## 9. よくある質問とトラブルシューティング

- **Q: USB を差して電源を入れても、Windows がそのまま起動してしまう。**
  - **A**: Windows の「高速スタートアップ」が有効になっているか、BIOS の起動順位で内蔵ディスクが優先されている可能性があります。電源投入直後に `Del` や `F2` キーで BIOS 設定画面を開き、USB メモリの起動優先順位を最上位に変更してください。
- **Q: 古い PC で画面が真っ暗なまま点滅カーソルが出る、または「Operating System not found」と表示される。**
  - **A**: レガシー BIOS 起動が必要です。**Rufus** で **パーティション構成: MBR**、**ターゲットシステム: BIOS (または UEFI-CSM)** を指定し、書き込みモードを **「DD モード」** で書き直してください。また、CPU が 32bit の場合は必ず 32bit 版 ISO（`SeibuRescue-18.04-i386.iso`）を使用してください。
- **Q: 最新の UEFI PC で「Secure Boot Violation」というエラーが出る。**
  - **A**: UEFI 設定画面（`F2` または `Del`）で一時的に **Secure Boot（セキュアブート）** を「Disabled（無効）」に設定してください。
