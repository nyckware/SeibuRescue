# SeibuRescue - システム＆ディスクリストア（復元）完全マニュアル（リストア専用版）

## 1. 重要な注意事項と概要

> [!CAUTION]
> **データ上書きに関する重大な注意**: ディスクイメージの復元を実行すると、**復元先として選択したドライブ内の既存データはすべて完全に消去・上書きされます**。復元先ドライブの選択に誤りがないか、必ず慎重に確認してください。

### リストア専用版（Restore-Only）について
本イメージは、工場の保守現場や緊急復旧作業において誤操作を防ぎ、迅速に作業が行えるよう最適化されています。メイン画面は復元機能に絞り込まれ、デスクトップ上には必須の保守ツール（**SeibuRescue**、**ディスク管理（Disks）**、**画面設定（ARandR）**）のみが配置されています。

## 2. 手順 1: PC を SeibuRescue USB メモリから起動する（ブート設定）

SeibuRescue を使用するには、作業対象の PC を内蔵ディスクではなく **SeibuRescue USB メモリ** から起動する必要があります。

### 方法 A: ブートメニュー（Boot Menu）を呼び出す（推奨・簡単）
1. 対象のパソコンの電源を完全に切ります（シャットダウン）。
2. **SeibuRescue USB メモリ** を PC の USB ポートに差し込みます。
3. 電源ボタンを押し、**すぐに「ブートメニュー呼び出しキー」を連打**（1秒に1回程度）します：

| パソコンメーカー / マザーボード | 代表的なブートメニューキー |
| :--- | :--- |
| **Dell（デル）** | `F12` |
| **HP / Compaq** | `F9` または `Esc` を押した後に `F9` |
| **Lenovo / ThinkPad** | `F12`（または `Enter` を押した後に `F12`） |
| **ASUS（エイスース）** | `F8` または `Esc` |
| **Acer（エイサー）** | `F12` または `Esc` |
| **東芝 / Dynabook** | `F12` |
| **富士通（Fujitsu）** | `F12` |
| **NEC** | `F12` |
| **その他 / 産業用PC / 自作機** | `F11`、`F12`、`F8`、または `Esc` |

4. 画面にブートデバイスの選択メニューが表示されたら、矢印キーで **USB メモリ**（例: `UEFI: USB Flash Drive`、`USB: Generic Flash Disk`、または `SanDisk` / `Kingston` などのブランド名）を選択します。
5. **Enter** キーを押して起動します。

### 方法 B: BIOS / UEFI 設定画面で起動優先順位（Boot Priority）を変更する
ブートメニューが表示されない場合は、BIOS の起動順位を変更します：
1. PC の電源を入れ、すぐに **BIOS 設定キー**（一般的には **`Del`**、**`F2`**、または **`F10`**）を連打します。
2. 矢印キーで **「Boot」** または **「起動 / スタートアップ」** タブに移動します。
3. **「Boot Option Priorities（起動優先順位）」** で、**USB メモリ** を一番上（1st Boot Device）に変更します。
4. 古い産業用 PC（Pentium 4、Atom、Windows XP/2000 世代）の場合は、**「Legacy Boot / CSM」** が有効になっていることを確認してください。
5. **`F10`** キー（Save & Exit）を押して設定を保存し、PC を再起動します。
6. 自動的に SeibuRescue の起動メニューが読み込まれます。

---

## 3. 手順 2: SeibuRescue の起動

1. PC が起動すると、軽量デスクトップ環境が自動的に立ち上がります。
2. リストア専用版では、起動と同時に **SeibuRescue のリストアウィザード** が自動表示されます（閉じてしまった場合は、デスクトップの「SeibuRescue」アイコンをダブルクリックしてください）。
3. 画面の案内に従って復元作業を進めます。

## 4. 手順 3: バックアップイメージの保存先を選択（ローカルまたはネットワーク）

復元したいバックアップイメージがどこに保存されているかを指定します。

![手順 1: 保存場所の選択](images/restore/restore_step1.png)
*(画像参照: `docs/images/restore/restore_step1.png` - 保存場所選択画面)*

- **Connected directly to my computer（ローカル接続ストレージ）**:
  - 外付けUSBハードディスク、別の内蔵ドライブ、またはSeibuRescue起動USBメモリ内のデータ用パーティション（BACKUPS等）にイメージがある場合はこちらを選択し、一覧から対象パーティションを選びます。
- **Shared over a network（ネットワーク共有 / NAS）**:
  - 社内サーバーやNASに保存されている場合は、**SMB/CIFS（Windows共有）**、**NFS**、**SSH/SFTP** から接続先を選択します。
- **Next（次へ）>** をクリックします。

## 5. 手順 4: 復元するバックアップイメージの選択

フォルダー一覧から、復元したいバックアップイメージを選択します。

![手順 2: 復元するバックアップフォルダーの選択](images/restore/restore_step2.png)
*(画像参照: `docs/images/restore/restore_step2.png` - イメージフォルダー参照画面)*

- フォルダー内を移動し、目的のバックアップフォルダーを指定します。
- SeibuRescue の標準的なフォルダー名は以下のようになっています：
  ```text
  YYYY-MM-DD-HHMM-img-seiburescue
  ```
- フォルダーをクリックして選択すると、イメージの整合性が自動確認されます。
- **Next（次へ）>** をクリックします。

## 6. 手順 5: 復元先ドライブ（ターゲット）の選択

バックアップデータを書き込む対象の物理ディスクを選択します。

![手順 3: 復元先ドライブの選択](images/restore/restore_step3.png)

- 復元先のドライブ行をクリックして選択します。
- **Next（次へ）>** をクリックします。

## 7. 手順 6: 復元パーティションの選択とパーティションテーブル割り当て

バックアップ内のどのパーティションを復元先に書き込むかを設定します。

![手順 4: 復元パーティションの選択](images/restore/restore_step4.png)
*(画像参照: `docs/images/restore/restore_step4.png` - パーティションテーブルマッピング画面)*

- **Restore partition table（パーティションテーブルの復元）**:
  - システム全体を復元する場合は、パーティションテーブル（MBR/GPT）の復元チェックを**有効（オン）**にしてください。元のブートローダーやパーティション構成が正確に再現されます。
- **パーティションの選択**:
  - OS全体、ブート領域、データ領域を復旧させるため、すべてのパーティションにチェックが入っていることを確認します。
- **容量の小さいディスクへの復元（Restoring to a smaller drive）**:
  - 元のディスクより容量が小さいディスクに復元する場合でも、実際のデータ使用量が復元先のディスク容量内に収まっていれば、SeibuRescue が自動的にパーティション境界を調整して安全に書き込みます。
- **Next（次へ）>** をクリックします。

データ書き込みを開始する前の最終確認画面です。

*(画像参照: `docs/images/restore/restore_step5.png` - 設定確認画面)*

- 表示内容を最終確認します：
  - **復元元イメージのパス**
  - **書き込み対象となる復元先ドライブ**

  - 復元完了後に自動で「再起動（Reboot computer）」または「シャットダウン（Shut down computer）」を行いたい場合は設定します。

画面上に最終警告のポップアップダイアログが表示されます：

## 9. 手順 8: 復元処理の実行と進捗確認

**Partclone** エンジンにより、イメージから圧縮データが解凍され、復元先ディスクへ書き込まれます。

![手順 8: 復元実行中](images/restore/restore_progress.png)
*(画像参照: `docs/images/restore/restore_progress.png` - 復元進捗バー)*

- リアルタイムで書き込み速度（MB/s）、経過時間、推定残り時間が表示されます。
- *処理実行中は、絶対にPCの電源を切ったりケーブルを抜いたりしないでください。*

## 10. 手順 9: 完了と初回起動

すべてのパーティションとブート領域の書き込みが正常に完了すると、サマリー画面が表示されます。

![手順 9: 復元完了サマリー](images/restore/restore_summary.png)
*(画像参照: `docs/images/restore/restore_summary.png` - 復元完了ダイアログ)*

1. 総所要時間と転送結果の概要が表示されます。
2. **Exit（終了）** をクリックしてウィザードを閉じます。
3. 画面右下の電源アイコンから **Reboot（再起動）** または **Shut Down（シャットダウン）** を選択します。
4. **PCの再起動中に SeibuRescue USB メモリを抜いてください**。パソコンが復元されたシステムから自動的に起動します。

## 11. トラブルシューティングとよくある質問（FAQ）

### よくあるトラブルと解決策
- **Q: リストア後に「No bootable device found」と表示されOSが起動しない。**
  - **A**: PCの BIOS/UEFI 起動モードを確認してください。古い MBR バックアップを復元した場合は BIOS で「Legacy Boot / CSM」を有効にし、新しい GPT/UEFI バックアップの場合は「UEFI Boot」が有効になっている必要があります。
- **Q: 異なるメーカーやCPU（Intel ⇄ AMD）のパソコンに復元できますか？**
  - **A**: はい、SeibuRescue はセクター単位で完全に複製します。近年の Windows 10/11 や Linux は初回起動時に新しいハードウェアのドライバを自動構成します。
- **Q: BitLocker で暗号化されていたドライブのイメージも復元できますか？**
  - **A**: はい、RAWパーティションモードで取得された BitLocker ドライブは、暗号化状態および暗号化キーを含めてそのまま復元されます。
