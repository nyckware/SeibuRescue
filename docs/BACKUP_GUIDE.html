Complete Disk & System Backup Guide

Step-by-step illustrated tutorial for creating full disk and partition images with SeibuRescue.

Overview & Preparation

SeibuRescue creates sector-accurate block-level backup images. It uses Partclone to read and copy only the used blocks of supported filesystems (NTFS, FAT32, ext4, exFAT, XFS, etc.), making the backup process fast and space-efficient.

Checklist before you start:
  • Destination Drive: Connect an external USB hard drive or verify that your USB stick has a secondary partition (e.g., BACKUPS) with sufficient free space.
  • Source Drive: Make sure the computer is fully shut down (not in Windows hibernation or Fast Startup mode).
1

Select Source Drive

Choose the physical storage drive that you want to back up from the table.

Step 1: Listing of detected internal and external storage drives
  • Examine the drive number, capacity (e.g., 500GB, 1TB), and model name carefully.
  • Click on the row corresponding to your source disk.
  • Click Next > to continue.
2

Select Partitions to Save

Select which partitions on the disk to include in the backup image.

Step 2: Partition selection list
Recommendation: Leave all partitions selected if you want a complete, bootable clone of your operating system (including bootloader, EFI system partition, and recovery volumes).

Click Next > to proceed.

3

Choose Destination Drive (Local or Network)

Specify where the backup image will be stored.

Step 3: Choosing local storage or network share
  • Connected directly to my computer: Choose this to save to an external USB drive, a secondary hard disk, or a dedicated data partition on your USB pendrive.
  • Shared over a network: Allows saving directly to a NAS or file server via SMB/CIFS (Windows Share), NFS, or SSH/SFTP.

Click Next >.

4

Select Target Folder

Browse and pick the folder on the destination drive where the backup files will reside.

Step 4: Folder navigation and creation dialog

Navigate to your storage folder (e.g., /mnt/backup/ or Backups/). You can also click the folder icon to create a new subfolder.

Click Next >.

5

Name Your Backup Image

Assign a descriptive name for your backup archive.

Step 5: Image naming and optional description
  • Default Name: SeibuRescue automatically suggests a timestamped name: YYYY-MM-DD-HHMM-img-seiburescue.
  • Custom Label: You can enter custom text (e.g., Factory-CNC-Machine01-FullBackup).
  • Optional Description: Add details such as machine model, installed software, or technician notes.

Click Next >.

6

Customize Compression Settings

Select the compression format and level.

Step 6: Choosing compression format (Zstandard, Gzip, or Uncompressed)
  • Zstandard (zstd) - Recommended: Modern, high-performance compression algorithm offering optimal speed and small image sizes.
  • Gzip (gzip): Traditional format for maximum backwards compatibility.
  • Uncompressed: Disables compression for fastest raw throughput when disk space is abundant.

Click Next >.

7

Confirmation & Rescue Options

Review the configured backup parameters before initiating the copy operation.

Step 7: Final summary and automated completion actions
  • Rescue Option: Check *"Rescue: Ignore filesystem inconsistencies and bad sectors"* ONLY if copying from a damaged or failing drive.
  • On Completion Action: Optionally set the PC to automatically reboot or shut down when the backup finishes.

Click Next > to begin copying.

8

Backup in Progress

The Partclone imaging engine runs and displays live performance metrics.

Step 8: Real-time progress bar, transfer rate, and time estimates

Monitor the transfer speed and remaining time. Do not unplug storage media while the process is active.

9

Completion & Summary

When all partitions have been imaged, the summary dialog confirms the successful completion.

Step 9: Success dialog confirming the backup is ready

Click Exit to return to the main menu. Your backup is now safely stored and can be restored at any time.
