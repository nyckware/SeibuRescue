Complete System Restore Guide (Restore-Only)

Step-by-step illustrated tutorial for recovering full disks and partitions from backup images.

Important Notice

⚠️ CRITICAL OVERWRITE WARNING:

Restoring a backup image will completely replace and erase all existing data on the destination storage drive. Please double-check your drive selection before proceeding.

The Restore-Only edition is streamlined for fast field recovery and industrial equipment maintenance. Redundant options have been removed to prevent operator error.

1

Boot the PC from the SeibuRescue USB Drive

The target computer must be started from the SeibuRescue USB drive rather than its internal disk.

Method A: One-Time Boot Menu (Recommended)

  1. Power off the computer completely.
  2. Insert your SeibuRescue USB flash drive into a USB port.
  3. Power on the PC and immediately press the Boot Menu key repeatedly (once per second) until the menu appears:
Computer / Motherboard Brand Boot Menu Key
DellF12
HP / CompaqF9 or Esc then F9
Lenovo / ThinkPadF12 (or Enter then F12)
ASUSF8 or Esc
AcerF12 or Esc
Toshiba / DynabookF12
FujitsuF12
Industrial PCs / OthersF11, F12, F8, or Esc

Select your USB Flash Drive from the list and press Enter.

Method B: Change Boot Priority in BIOS / UEFI

  • Power on the machine and press Del, F2, or F10 to open BIOS Setup.
  • Under Boot Priority, move the USB drive to the 1st Boot Device position.
  • On older industrial machines (Pentium 4 / Atom), ensure Legacy Boot / CSM is enabled.
  • Press F10 (Save and Exit).
2

Start SeibuRescue

The system will load the desktop environment and immediately display the SeibuRescue Restore Wizard.

(If accidentally closed, double-click the SeibuRescue icon on the desktop).

3

Select Image Location

Choose where the backup image you wish to restore is stored.

Step 3: Selecting local drive or network share location
  • Connected directly to my computer: Choose this if your backup is stored on an external USB hard drive, a second internal drive, or on the USB stick's data partition (e.g., BACKUPS).
  • Shared over a network: Allows accessing backup images directly from a NAS or Windows shared folder via SMB/CIFS, NFS, or SSH.

Click Next >.

4

Select Backup Image Folder

Browse through your folders and select the specific backup image archive.

Step 4: Image folder selection and verification

Standard SeibuRescue image folders are named YYYY-MM-DD-HHMM-img-seiburescue. Click on the desired backup folder.

Click Next >.

5

Select Destination Drive to Overwrite

Select the internal storage drive that will receive the restored operating system.

Step 5: Target drive selection
Check carefully: Verify the capacity and model name. All existing partitions on this disk will be deleted and replaced.

Click Next >.

6

Select Partitions & Partition Table

Choose which partitions from the backup to write to the destination disk.

Step 6: Partition mapping and partition table restoration
  • Restore partition table: Keep this checked for a full system recovery so MBR/GPT structures and bootloaders are recreated.
  • All Partitions: Keep all partitions checked to restore the full operating system.

Click Next >.

7

Confirm & Start Restoration

Review the configuration summary and confirm the overwrite operation.

Step 7: Final review screen

Click Next >. A safety warning dialog will appear:

Safety confirmation dialog

Click Yes to begin writing data to the target disk.

8

Restoration in Progress

The Partclone restoration engine writes all data blocks back to the target disk.

Step 8: Live write speed and time remaining

Do not power off the machine or disconnect any cables while data is being written.

9

Completion & Reboot

Once finished, the success summary dialog will be displayed.

Step 9: Success dialog confirming the restore is complete
  1. Click Exit.
  2. Click the power button in the bottom right corner and select Reboot.
  3. Unplug the SeibuRescue USB drive as the computer restarts.
  4. Your computer will boot normally into the restored system!
