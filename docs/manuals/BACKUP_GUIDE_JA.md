## 1. 概要と事前準備

### SeibuRescue のバックアップ機能について
SeibuRescue は、ディスクのセクター構造を正確に保持したイメージバックアップを作成します。**Partclone** エンジンにより、サポートされているファイルシステム（NTFS, FAT32, ext2/3/4, exFAT, XFS, Btrfs など）の使用済み領域のみを効率的に読み取るため、高速かつファイルサイズを最小限に抑えたバックアップが可能です。

### バックアップ前の確認事項
- **保存先の空き容量**: 保存先の外付けUSBハードディスク、USBメモリのデータ領域、またはNAS（ネットワーク共有）に十分な空き容量があることを確認してください（使用済みデータ量の約30%〜70%程度が目安です）。
- **ドライブの状態（不良セクタ等）**: 不良セクタが発生している故障しかけのディスクをバックアップする場合は、手順7の「レスキューオプション」を有効にしてください。
- **暗号化ドライブ（BitLocker）**: Windows BitLocker で暗号化されているドライブをバックアップする場合は、[暗号化ディスク解除マニュアル（DISK_UNLOCK_GUIDE_JA.md）](DISK_UNLOCK_GUIDE_JA.md) を参照してロックを解除するか、RAWパーティション単位での取得を行います。

## 2. 手順 1: PC を SeibuRescue USB メモリから起動する（ブート設定）

バックアップ作業を行うには、作業対象の PC を内蔵ディスクではなく **SeibuRescue USB メモリ** から起動する必要があります。

### 方法 A: ブートメニュー（Boot Menu）を呼び出す（推奨・簡単）
1. 対象パソコンの電源を完全に切ります（シャットダウン）。
2. **SeibuRescue USB メモリ** を PC の USB ポートに差し込みます。
3. 電源ボタンを押し、**すぐに「ブートメニュー呼び出しキー」を連打**（1秒に1回程度）します：

| パソコンメーカー / マザーボード | 代表的なブートメニューキー |
| :--- | :--- |
| **Dell（デル）** | `F12` |
| **HP / Compaq** | `F9` または `Esc` を押した後に `F9` |
| **Lenovo / ThinkPad** | `F12`（または `Enter` を押した後に `F12`） |
| **ASUS（エイスース）** | `F8` または `Esc` |
| **Acer（エイサー）** | `F12` または `Esc` |
| **東芝 / Dynabook** | `F12` |
| **富士通（Fujitsu）** | `F12` |
| **NEC** | `F12` |
| **その他 / 産業用PC / 自作機** | `F11`、`F12`、`F8`、または `Esc` |

4. 画面にブートデバイス選択メニューが表示されたら、矢印キーで **USB メモリ**（例: `UEFI: USB Flash Drive`、`USB: Generic Flash Disk` など）を選択します。
5. **Enter** キーを押して起動します。

### 方法 B: BIOS / UEFI 設定画面で起動優先順位（Boot Priority）を変更する
- ブートメニューが表示されない場合は、電源投入直後に **`Del`**、**`F2`**、または **`F10`** を連打して BIOS 画面を開きます。
- **Boot Priority（起動優先順位）** で、USB メモリを **1st Boot Device**（最優先）に設定します。
- 古い産業用 PC（Pentium 4、Atom世代）の場合は、**Legacy Boot / CSM** が有効になっていることを確認してください。
- **`F10`** キー（Save & Exit）を押して設定を保存します。PC が自動再起動し、SeibuRescue が立ち上がります。

## 3. 手順 2: SeibuRescue の起動

1. デスクトップ環境が自動的に読み込まれます。
2. 画面中央に **SeibuRescue** のメイン画面が表示されます（閉じてしまった場合は、デスクトップ上の「SeibuRescue」アイコンをダブルクリックしてください）。
3. メインメニューから **「Backup（バックアップ）」** ボタンをクリックします。

## 4. 手順 3: バックアップ元ドライブ（ソース）の選択

バックアップを取りたい元の物理ドライブを選択します。

![手順 1: バックアップ元ドライブの選択](images/backup/backup_step1.png)
*(画像参照: `docs/images/backup/backup_step1.png` - バックアップ元ドライブ選択画面)*

- **ドライブ一覧**: 接続されている内蔵・外付けドライブの番号、容量、モデル名、パーティション構成が表示されます。
- **注意点**: ドライブの容量とモデル名をしっかり確認し、バックアップ対象のディスク（例: `Drive #1 - 50GB ATA VBOX HARDDISK` や `Drive #1 - 512GB NVMe SSD`）を選択してください。
- **詳細オプション**: 対象のドライブが一覧に表示されない場合のみ、画面下の「Show hidden devices（非表示デバイスを表示）」にチェックを入れます。
- **Next（次へ）>** をクリックします。

## 5. 手順 4: 保存するパーティションの選択

選択したドライブ内のどのパーティションをバックアップに含めるかを指定します。

![手順 2: 保存するパーティションの選択](images/backup/backup_step2.png)
*(画像参照: `docs/images/backup/backup_step2.png` - パーティション選択画面)*

- **推奨設定**: OSを含めて丸ごと復元可能なブータブルバックアップを作成する場合は、**すべてのパーティションにチェックを入れたまま（デフォルト）** にしてください。
- 特定のデータドライブのみを個別保存したい場合は、不要なパーティションのチェックを外すことも可能です。
- **Next（次へ）>** をクリックします。

## 6. 手順 5: 保存先ドライブの選択（ローカルドライブまたはネットワーク共有）

作成するバックアップイメージの保存先を指定します。

![手順 3: 保存先ドライブの選択](images/backup/backup_step3.png)
*(画像参照: `docs/images/backup/backup_step3.png` - 保存先ドライブ選択画面)*

- **Connected directly to my computer（ローカル接続ドライブ）**:
  - 外付けUSBハードディスク、別の内蔵ドライブ、またはSeibuRescue起動USBメモリ内のデータ用パーティション（BACKUPS等）に保存する場合は、こちらを選択し一覧から対象パーティションを選びます（例: `Drive 2, Partition 1 [NTFS]`）。
- **Shared over a network（ネットワーク共有 / NAS）**:
  - **SMB/CIFS（Windows共有フォルダー / NAS）**、**NFS**、**SSH/SFTP** 経由での保存に対応しています。
  - 選択すると、サーバーIP、共有名、ユーザー名、パスワードの入力画面が表示されます。
- **Next（次へ）>** をクリックします。

## 7. 手順 6: 保存先フォルダーの指定

保存先ドライブ内のどのフォルダーにイメージを作成するかを選択します。

![手順 4: 保存先フォルダーの指定](images/backup/backup_step4.png)
*(画像参照: `docs/images/backup/backup_step4.png` - ディレクトリ選択画面)*

- フォルダーブラウザを使用して、バックアップを保存したいディレクトリ（例: `/mnt/backup/` や `Backups/` など）を指定します。
- 必要に応じて、この画面から新規フォルダーを作成することも可能です。
- **Next（次へ）>** をクリックします。

## 8. 手順 7: バックアップイメージ名の設定

作成するバックアップフォルダーの名前を指定します。

![手順 5: バックアップイメージ名の設定](images/backup/backup_step5.png)
*(画像参照: `docs/images/backup/backup_step5.png` - イメージ名入力画面)*

- **デフォルトの命名規則**: SeibuRescue では、日付と時刻を含んだ以下のフォーマットが自動的に提案されます：
  ```text
  YYYY-MM-DD-HHMM-img-seiburescue
  ```
  *(例: `2026-10-29-0915-img-seiburescue`)*
- **名前のカスタマイズ**: 分かりやすい管理名（例: `CNC-Machine01-WinXP-Backup` など）に変更することも可能です。
- **メモ／説明（Description）**: 必要に応じて、バックアップの目的やバージョン情報などの補足メモを入力できます（メタデータとして保存されます）。
- **Next（次へ）>** をクリックします。

## 9. 手順 8: 圧縮形式の設定（Zstandard / Gzip / 無圧縮）

バックアップイメージファイルの圧縮方式とレベルを選択します。

![手順 6: 圧縮形式のカスタマイズ](images/backup/backup_step6_zstandard.png)
*(画像参照: `docs/images/backup/backup_step6_zstandard.png` - 圧縮オプション画面)*

- **Zstandard（zstd） - 推奨**:
  - 高速処理と高圧縮率を両立した最新のアルゴリズムです。
  - 圧縮レベルは通常 **レベル6〜16** が実用的で推奨されます。
- **Gzip（gzip）**:
  - 従来の標準的な圧縮形式です（互換性重視）。
- **Uncompressed（無圧縮）**:
  - 圧縮を行わずそのまま保存します。書き込み速度は最速ですが、元データと同じだけのディスク容量が必要になります。
- **Next（次へ）>** をクリックします。

## 10. 手順 9: 最終設定確認とレスキューモード

バックアップ開始前の最終設定確認画面です。

![手順 7: バックアップ設定の確認](images/backup/backup_step7.png)
*(画像参照: `docs/images/backup/backup_step7.png` - 最終確認画面)*

- 表示内容を確認します：
  - **バックアップ元ドライブと対象パーティション**
  - **保存先パスとイメージ名**
  - **圧縮形式**
- **Rescue Option（不整合や不良セクタを無視するレスキュー設定）**:
  - ディスクの経年劣化や物理エラーによって通常バックアップが中断してしまう場合のみ、このチェックボックスをオンにしてください。
- **完了後の動作（On successful completion）**:
  - バックアップ完了後に「何もしない（Do nothing）」、「再起動（Reboot computer）」、「シャットダウン（Shut down computer）」から選択できます。
- **Next（次へ）>** をクリックすると、バックアップ処理が開始されます。

## 13. ベストプラクティスとよくある質問（FAQ）

### 運用のベストプラクティス
1. **イメージの検証（Verify Image）**: バックアップ直後に、SeibuRescue メイン画面の「Verify Image」を実行して、ファイルが破損なく完全に読み込めるか確認することをおすすめします。
2. **世代管理**: 古いバックアップを即座に上書きせず、トラブルに備えて少なくとも2〜3世代分のバックアップを保持してください。
3. **ファイル単位の取り出し（Image Explorer）**: 将来、丸ごと復元するのではなく一部のファイルだけを取り出したい場合は、メインメニューの「Image Explorer」を使ってバックアップイメージをマウントし、中身を取り出すことができます。

### よくある質問
- **Q: バックアップ元より小さい容量のディスクに復元できますか？**
  - はい、実際のデータ使用量が復元先ディスクの容量に収まる場合、SeibuRescue は小さい容量のディスクへの復元を自動サポートします。
- **Q: Clonezilla（クローンギラ）のバックアップイメージと互換性はありますか？**
  - はい、SeibuRescue のバックアップイメージは Clonezilla と完全な相互互換性があります。
