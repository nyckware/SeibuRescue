USB Bootable Drive Creation Guide

How to flash, burn, and configure SeibuRescue ISO images onto a USB flash drive

1

Select the Appropriate ISO Variant

Before preparing your USB flash drive, choose the correct ISO image variant according to your hardware environment:

ISO Filename Architecture Minimum RAM Best For
SeibuRescue-24.04-amd64.iso 64-bit (x86_64) 2 GB+ Modern workstations, laptops, UEFI & BIOS servers (Full features).
SeibuRescue-18.04-i386.iso 32-bit (i386) 256 MB – 512 MB Legacy factory PCs, Pentium 4, Intel Atom, low-RAM machinery.
SeibuRescue-RestoreOnly-24.04-amd64.iso 64-bit (x86_64) 2 GB+ Fast field deployment & system recovery (Restore-only).
SeibuRescue-RestoreOnly-18.04-i386.iso 32-bit (i386) 256 MB – 512 MB Factory machine recovery & disaster restoration (Restore-only).
Important: Always verify that all important files on your USB drive are backed up. Flashing an ISO will completely erase the target USB stick!
2

Method 1: Rufus (Windows - Recommended for Factory PCs)

Rufus provides exact control over MBR partition schemes and BIOS/UEFI boot modes, making it the most reliable tool for older industrial motherboards.

  1. Download Rufus (portable edition) from https://rufus.ie.
  2. Plug your USB flash drive into the Windows PC and open Rufus.
  3. Configure the following options:
    • Device: Select your USB drive from the dropdown.
    • Boot selection: Click SELECT and choose your SeibuRescue-*.iso.
    • Partition scheme: Select MBR (Universal compatibility: boots on both Legacy BIOS and modern UEFI).
    • Target system: Select BIOS (or UEFI-CSM).
    • File system: FAT32 (Default).
  4. Click START.
  5. If prompted with "ISOHybrid image detected", select Write in ISO Image mode (Recommended) and click OK.
  6. Confirm the data deletion prompt. When the progress bar shows READY, click CLOSE.
3

Method 2: BalenaEtcher (Windows, macOS, Linux)

BalenaEtcher is a simple 3-step cross-platform flasher:

  1. Download and install BalenaEtcher from https://etcher.balena.io.
  2. Insert your USB flash drive.
  3. Click Flash from file and pick your SeibuRescue-*.iso.
  4. Click Select target and check your USB drive.
  5. Click Flash! and confirm administrator permissions.
  6. Wait for the writing and validation to finish (100%), then safely remove the drive.
4

Method 3: Linux Command Line (dd Command)

On Linux systems, you can write the ISO directly with byte-accurate sector imaging:

  1. Open a terminal and find your USB drive identifier: 
    lsblk -d -o NAME,SIZE,MODEL,TRAN
    (Identify the drive letter, e.g. /dev/sdb. Do NOT specify a partition number like /dev/sdb1).
  2. Unmount any active partitions on the USB: 
    sudo umount /dev/sdX* 2>/dev/null || true
  3. Write the ISO image to the USB drive: 
    sudo dd if=SeibuRescue-24.04-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync
  4. Flush system disk write buffers: 
    sync
5

Method 4: Ventoy (Multi-Boot USB)

Ventoy lets you hold multiple ISOs (e.g., both 64-bit and 32-bit versions) on a single flash drive by simply copying files:

  1. Download Ventoy from https://www.ventoy.net.
  2. Install Ventoy onto your USB flash drive.
  3. Open the newly created Ventoy partition in your file explorer.
  4. Drag and drop SeibuRescue-24.04-amd64.iso and/or SeibuRescue-18.04-i386.iso into the drive.
  5. Boot the PC from the USB and select the ISO from the Ventoy menu.
Industrial PC Note: Some older industrial motherboards (Pentium 4 / early Atom from 2000–2010) may fail to load Ventoy's bootloader. For maximum legacy factory reliability, use Rufus (MBR mode) or dd.
6

Pro Tip: Creating a Dedicated Backup Storage Partition on the USB

Since the SeibuRescue operating system takes only ~1 GB to 1.6 GB, a 32 GB or 64 GB flash drive has plenty of unused space. You can format the remaining space as a storage partition to hold system backup images directly on the same drive!

How to create the secondary partition:
  1. Open GParted or KDE Partition Manager (inside SeibuRescue or on Linux).
  2. Select the USB flash drive.
  3. In the unallocated free space, create a new partition:
    • File System: NTFS (recommended for Windows & Linux compatibility and large file support) or exFAT.
    • Partition Label: BACKUPS.
  4. Apply changes. When running SeibuRescue, this BACKUPS partition will appear immediately in the destination drive list!
7

Booting the PC from the USB Drive

Plug the USB flash drive into the target computer, turn it on, and immediately tap the Boot Menu key repeatedly:

Computer / Motherboard Brand Boot Menu Key
DellF12
HP / CompaqF9 or Esc then F9
Lenovo / ThinkPadF12
ASUSF8 or Esc
Acer / Toshiba / Fujitsu / NECF12
Industrial PCs (Advantech, Kontron, etc.)F11, F12, F8, or Esc

Select your USB device from the list and press Enter to launch SeibuRescue.
