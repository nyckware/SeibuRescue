ブータブル USB メモリ作成マニュアル

SeibuRescue の ISO イメージを USB メモリへ安全・確実に書き込む手順の解説

1

手順 1: 適切な ISO バリエーションの選定

書き込み作業を行う前に、作業対象となる PC の環境や用途に合わせて適切な ISO ファイルを選択してください：

ISO ファイル名 対象アーキテクチャ 推奨メモリ (RAM) 最適な用途
SeibuRescue-24.04-amd64.iso 64ビット (x86_64) 2 GB 以上 現代の一般的なPC、ワークステーション、サーバー（全機能搭載）。
SeibuRescue-18.04-i386.iso 32ビット (i386) 256 MB 〜 512 MB 工場の旧型設備PC、Pentium 4、初期Atom、低メモリ装置向け。
SeibuRescue-RestoreOnly-24.04-amd64.iso 64ビット (x86_64) 2 GB 以上 保守現場での迅速なバックアップ復元・リストア専用版。
SeibuRescue-RestoreOnly-18.04-i386.iso 32ビット (i386) 256 MB 〜 512 MB 工場マシンのトラブル復旧に特化した軽量な復元専用版。
事前確認： 書き込みを実行すると、USB メモリ内の既存データはすべて消去されます。必要なデータは事前に必ずバックアップしてください。
2

方法 1: Rufus（Windows 推奨・産業用および旧型PC向け）

Rufus は、MBR パーティション方式やレガシー BIOS 起動モードを正確に指定できるため、工場の産業用 PC や旧型機において最も推奨されるツールです。

  1. https://rufus.ie から Rufus（ポータブル版推奨）をダウンロードします。
  2. USB メモリを Windows PC に挿入し、Rufus を起動します。
  3. 以下の設定を行います：
    • デバイス： 接続した USB メモリを選択します。
    • ブートの種類： 「選択」 をクリックし、ダウンロードした SeibuRescue-*.iso を指定します。
    • パーティション構成： 「MBR」 を選択 （※ 旧型 BIOS 機と最新 UEFI 機の両方で起動可能）。
    • ターゲットシステム： 「BIOS (または UEFI-CSM)」 を選択。
    • ファイルシステム： FAT32 (既定)。
  4. 「スタート」 をクリックします。
  5. 「ISOHybrid イメージが検出されました」と表示された場合は、「ISO イメージモードで書き込む (推奨)」 を選んで 「OK」 を押します。
  6. 消去の警告で 「OK」 をクリックします。進捗バーが「準備完了」になったら 「閉じる」 を押して完了です。
3

方法 2: BalenaEtcher（Windows / macOS / Linux 簡単操作）

BalenaEtcher は、わずか3ステップで書き込みができるシンプルなクロスプラットフォームツールです：

  1. https://etcher.balena.io から BalenaEtcher をダウンロードしてインストールします。
  2. USB メモリを PC に接続します。
  3. Flash from file をクリックし、SeibuRescue-*.iso を選択します。
  4. Select target をクリックし、対象の USB メモリにチェックを入れます。
  5. Flash! をクリックし、書き込みを開始します。
  6. 検証が 100%（Flash Complete!）になったら、USB メモリを安全に取り外します。
4

方法 3: Linux ターミナル（dd コマンド）

Linux 環境では、OS 標準の dd コマンドで正確なセクター書き込みが行えます：

  1. ターミナルを開き、USB メモリのデバイス名を確認します： 
    lsblk -d -o NAME,SIZE,MODEL,TRAN
    （※ /dev/sdb1 などのパーティションではなく、/dev/sdb のようにドライブ全体を指定します）。
  2. 自動マウントされている場合はアンマウントします： 
    sudo umount /dev/sdX* 2>/dev/null || true
  3. ISO を USB デバイスへ直接書き込みます： 
    sudo dd if=SeibuRescue-24.04-amd64.iso of=/dev/sdX bs=4M status=progress oflag=sync
  4. 書き込みバッファを同期します： 
    sync
5

方法 4: Ventoy（複数 ISO をまとめられるマルチブート）

Ventoy を使うと、1本の USB メモリに 64bit版と 32bit版の ISO ファイルを両方入れておき、起動時に選んで起動できます：

  1. https://www.ventoy.net から Ventoy を入手し、USB メモリへインストールします。
  2. PC に表示された Ventoy ドライブを開きます。
  3. SeibuRescue-24.04-amd64.iso や SeibuRescue-18.04-i386.iso をそのままコピーします。
  4. PC を起動すると、Ventoy のメニューから起動したい ISO を選択できます。
産業用 PC での注意： 工場にある古い産業用マザーボード（2000〜2010年頃の Pentium 4 / Atom 世代）では、Ventoy のブートローダーが初期化できず起動しない場合があります。古い現場装置では、方法 1（Rufus MBRモード） または 方法 3（dd） を強く推奨します。
6

活用テクニック: 同じ USB 内に「バックアップ保存領域」を作成する

SeibuRescue のシステム容量は 1GB〜1.6GB 程度のため、32GB や 64GB などの USB メモリを使用する場合、残りの空きスペースを「バックアップイメージ保存用のデータパーティション」として有効活用できます。

第2パーティションの作成手順：
  1. SeibuRescue 上（または Linux PC）で GParted（パーティションエディタ）を開きます。
  2. 対象の USB メモリを選択します。
  3. 未割り当て（Unallocated）の空き領域に新規パーティションを作成します：
    • ファイルシステム： NTFS（Windows と Linux の両方で読み書きでき、大容量ファイルに対応するため推奨）または exFAT。
    • ラベル： BACKUPS。
  4. 変更を適用します。SeibuRescue でバックアップを実行する際、保存先ドライブ一覧にこの BACKUPS がローカルドライブとして即座に表示されます！
7

作成した USB メモリからの起動（ブート手順）

作業対象のパソコンに USB メモリを差し込み、電源を入れてすぐに各メーカーの **「ブートメニュー呼び出しキー」** を連打します：

パソコンメーカー / マザーボード 代表的なブートメニューキー
Dell（デル）F12
HP / CompaqF9 または Esc の後に F9
Lenovo / ThinkPadF12
ASUS（エイスース）F8 または Esc
Acer / 東芝 / 富士通 / NECF12
産業用 PC / その他（Advantech 等）F11、F12、F8、または Esc

一覧から USB メモリを選択して Enter を押すと、SeibuRescue が起動します。
