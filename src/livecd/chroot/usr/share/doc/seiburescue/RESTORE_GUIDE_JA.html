システム＆ディスクリストア完全マニュアル（リストア専用版）

バックアップイメージからディスク全体やOSを復元する手順を画面付きで解説

重要な注意事項

⚠️ データ上書きに関する重大な警告：

復元を実行すると、選択した復元先ドライブの既存データはすべて完全に消去・上書きされます。対象ドライブの選択に誤りがないか必ずご確認ください。

このリストア専用版（Restore-Only）は、工場の保守現場などで誤操作を防ぎ、迅速かつ安全に復旧作業が行えるよう操作画面が最適化されています。

1

手順 1: PC を SeibuRescue USB メモリから起動する

復元作業を行うパソコンを、内蔵ディスクではなく SeibuRescue USB メモリから起動します。

方法 A: ブートメニュー（Boot Menu）を呼び出す（推奨）

  1. 対象のパソコンの電源を完全に切ります。
  2. SeibuRescue USB メモリ を PC の USB ポートに差し込みます。
  3. 電源ボタンを入れ、すぐに以下のキーを連打（1秒に1回程度）します：
パソコンメーカー / マザーボード 代表的なブートメニューキー
Dell（デル）F12
HP / CompaqF9 または Esc → F9
Lenovo / ThinkPadF12（または Enter → F12）
ASUS（エイスース）F8 または Esc
Acer（エイサー）F12 または Esc
東芝 / DynabookF12
富士通（Fujitsu）F12
NECF12
産業用PC / その他F11、F12、F8、または Esc

一覧から USB メモリ を選択して Enter を押します。

方法 B: BIOS / UEFI 設定画面で起動順位を変更する

  • 電源投入直後に Del、F2、または F10 を連打して BIOS 画面を開きます。
  • Boot Priority（起動優先順位） で、USB メモリを 1st Boot Device に設定します。
  • 古い産業用PC（Pentium 4、Atom世代）の場合は、Legacy Boot / CSM が有効になっていることを確認してください。
  • F10 キー（Save & Exit）を押して設定を保存します。
2

手順 2: SeibuRescue の起動

デスクトップが立ち上がると、自動的に SeibuRescue リストアウィザード が表示されます。

（誤って閉じてしまった場合は、デスクトップの SeibuRescue アイコンをダブルクリックしてください）。

3

手順 3: バックアップイメージの保存先を選択

復元したいバックアップファイルがどこにあるかを指定します。

手順 3: ローカル接続ストレージまたはネットワーク共有の選択
  • Connected directly to my computer： 外付けUSBハードディスク、別の内蔵ドライブ、またはUSBメモリ内のデータ領域（BACKUPS等）に保存されている場合はこちらを選択します。
  • Shared over a network： SMB/CIFS（Windows共有 / NAS）、NFS、SSH/SFTP 経由でネットワークから復元できます。

Next（次へ）> をクリックします。

4

手順 4: 復元するバックアップイメージの選択

復元したいバックアップフォルダーを指定します。

手順 4: イメージフォルダーの選択と整合性確認

SeibuRescue の標準的なフォルダー名は YYYY-MM-DD-HHMM-img-seiburescue です。目的のフォルダーをクリックして選択します。

Next（次へ）> をクリックします。

5

手順 5: 復元先ドライブ（書き込み対象）の選択

データを復元して書き込む対象の物理ディスクを選択します。

手順 5: 書き込み対象ドライブの選択
容量とモデル名を再確認してください： ここで選択したドライブの内容はすべて上書き・消去されます。

Next（次へ）> をクリックします。

6

手順 6: 復元パーティションの選択

バックアップ内のどのパーティションを復元先に書き込むかを指定します。

手順 6: パーティションテーブルの復元と領域割り当て
  • Restore partition table（パーティションテーブルの復元）： システム全体を復元する場合はチェックを入れたままにします（ブートローダーやMBR/GPT情報が再構築されます）。
  • すべてのパーティション： OSを丸ごと復旧するため、全パーティションにチェックを入れます。

Next（次へ）> をクリックします。

7

手順 7: 上書きの最終確認とリストア開始

設定内容を確認し、ディスクへの書き込みを開始します。

手順 7: 設定概要の最終確認画面

Next（次へ）> をクリックすると、最終警告のポップアップダイアログが表示されます：

上書き実行の確認ダイアログ

Yes をクリックすると、復元先ディスクへの書き込みが開始されます。

8

手順 8: 復元処理の実行と進捗確認

Partclone により、バックアップデータが解凍されディスクに書き込まれます。

手順 8: 書き込み速度、経過時間、推定残り時間のリアルタイム表示

書き込み処理中は、PCの電源を切ったりケーブルを抜いたりしないでください。

9

手順 9: 完了とパソコンの再起動

すべての処理が完了すると、成功メッセージが表示されます。

手順 9: 正常終了ダイアログ
  1. Exit（終了） をクリックします。
  2. 画面右下の電源アイコンから Reboot（再起動） を選択します。
  3. 再起動中に SeibuRescue USB メモリを抜いてください。
  4. パソコンが復元されたオペレーティングシステムから正常に起動します。
